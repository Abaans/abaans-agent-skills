# Examples and review cases

## Research only

Request: “Research three serif directions for Northline, a fictional outdoor journal. Commercial desktop use matters. Do not install anything.”

Find current primary-source font information and return a comparison. Do not invent a font's license or claim Figma verification. Use `not requested` for installation/rendering. Completion is the sourced shortlist with uncertainties, not a forced desktop session.

Suggested comparison fields: family/style, source, relevant license terms, glyph coverage, brand fit, installation status, rendering status and recommendation.

## Figma comparison

Request: “Compare these two authorized font files on the supplied wordmark frame. Preserve the current treatment.”

Duplicate the baseline, inspect the license and files, install only the requested styles through the supported route, and confirm their actual names in Figma. Use matched specimen settings before changing tracking. Reopen the saved file when needed to verify persistence.

## Reviewer checks

- A font marked personal-use-only stays exploration-only for a commercial brand.
- A successful Font Book install with no Figma font-picker result remains Figma-unverified.
- A strong wordmark with a missing required character is not a suitable finalist.
- Missing fonts or a locked design file do not justify replacing the approved baseline.
